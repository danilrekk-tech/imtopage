# Обновление проекта

## Новые функции

### Удаление проектов
В разделе «Мои проекты» у каждой карточки есть меню действий. Удаление подтверждается через диалог и удаляет запись проекта вместе с исходным изображением. Связанные логи и приглашения удаляются каскадно через существующие ограничения базы данных.

### Скачать ZIP из старого проекта
На странице `/p/:projectId` доступны отдельные действия:
- Скачать HTML — исходный самодостаточный HTML;
- Скачать ZIP — архив с `index.html` и README.

### Оценка визуального соответствия
На странице проекта появился блок «Визуальное соответствие». Он сравнивает исходный скриншот с текущим живым превью и показывает процент, уровень качества и отдельные метрики.

Оценка выполняется в браузере. Если политика CORS или ограничения браузера не позволяют получить пиксели, сервис автоматически переключается на ориентировочную оценку по геометрии и явно сообщает об этом пользователю. Процент является автоматическим ориентиром, а не экспертной оценкой дизайнера.
