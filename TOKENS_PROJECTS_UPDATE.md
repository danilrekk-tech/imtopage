# Projects + Design Tokens update

## Мои проекты
- Поиск по названию.
- Фильтр по статусу: все / готово / в работе / ошибки.
- Сортировка по дате.
- Переключение сетка / список.
- Избранное хранится локально в браузере.
- Быстрый переход в проект и удаление с подтверждением.
- Старый проект продолжает иметь экспорт HTML/ZIP на странице проекта.

## Дизайн-токены
- 7 цветовых токенов: accent, secondary, background, surface, text, muted, border.
- Типографика.
- Радиус.
- Плотность интерфейса.
- Тени.
- Быстрые акцентные цвета.
- Сохранение пользовательских дизайн-систем в браузере (до 12 пресетов).
- Загрузка сохранённого пресета, удаление, сброс и копирование JSON.
- Токены сохраняются в project component_map и показываются на странице старого проекта.
- Из старого проекта можно перенести его дизайн-систему в новый прототип.
