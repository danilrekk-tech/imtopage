# Image → Interactive — redesign

Полный визуальный редизайн интерфейса без изменения основной логики генерации.

## Что изменено
- Новый dark AI-workspace с фиолетовым градиентным акцентом.
- Постоянный sidebar: Новый прототип, Мои проекты, шаблоны, токены, история, экспорт, настройки.
- Новый верхний workspace bar с режимом черновика, предпросмотром и экспортом.
- Новый hero-блок с визуальным элементом конвертации макета в код.
- Обновлена зона загрузки до 3 экранов с миниатюрами.
- Переработана зона результата: вкладки превью/рядом/сравнение, инспектор, экспорт и действия.
- Сохранены существующие server functions, Supabase, генерация, редактирование, accessibility audit, share и экспорт.
- Адаптивная версия для планшета и мобильного.

Графика подключается локально, поэтому после загрузки проекта в Lovable не требуется внешний URL для hero-иллюстрации.

## Публичный просмотр прототипа

Публичные ссылки в режиме «Все по ссылке» теперь работают как самостоятельные страницы. GET-запрос `/s/:token` отдаёт сохранённый `generated_html` напрямую с `Content-Type: text/html`, поэтому третье лицо видит полноценный сайт прототипа на весь экран, а не iframe внутри интерфейса Image → Interactive.

В окне «Поделиться» добавлены действия «Копировать ссылку» и «Открыть сайт». Режим «Конкретные люди» оставлен через приложение, чтобы сохранить проверку авторизованного e-mail.
